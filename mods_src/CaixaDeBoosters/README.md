# Booster box (behavior mod for Tag Force Recomp)

In the card shop, on the pack selection screen, press **R** (Tab on the keyboard, or W in the classic layout; RB on a controller): the game's own message window asks
"Buy all N packs for X DP?"; YES buys every remaining pack of that booster at once (limited by your DP) and the game opens them in sequence.
See `docs/MODS.md` for how it works; the sources (`caixa_boosters.cpp`) are a good first example of a behavior mod.
